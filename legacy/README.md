# Legacy static pages (not deployed)

These are the pre-React pages (dashboard, project, operations, per-tab redirects, reconcile) and the old
address-service script. They were retired when the React app became the only authenticated UI
(migration Phase 5). They are kept only as a reference for UI parity and are **not** copied into
`dist/` by `scripts/postbuild.js`. Delete this folder once nobody needs the reference.
